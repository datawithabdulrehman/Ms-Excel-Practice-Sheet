# Ms-Excel-Practice-Sheet

Welcome to the **Microsoft Excel Practice Sheet** repository! This repository is designed to help you build, practice, and master your data analysis skills in Excel, covering everything from core foundational principles to advanced data transformation and modeling techniques.

## 📊 Repository Structure

The repository contains structured practice workbooks categorized by skill level and specific Excel functionalities:

*   **`Section_1_Excel_Basics_Practice_File.xlsx`**: Master core formulas, formatting, absolute/relative referencing, and basic spreadsheet operations.
*   **`Section_2_Excel_Wrangling_Practice_File.xlsx`**: Focus on cleaning, filtering, sorting, and prepping messy datasets for analysis.
*   **`Section_3_Pivot_Unpivot.xlsx`**: Dive deep into summarizing tabular information and converting cross-tabulated data into normalized columns.
*   **`Section_3_PowerQuery_Wrangling_Practice.xlsx`**: Advance your automation pipeline workflows using Power Query to clean, extract, and merge multiple data streams.
*   **`Section_4_DataModeling_DAX_Module.xlsx`**: Learn the foundations of Business Intelligence inside Excel by building relationships and writing DAX measures.
*   **`Section_5_PivotTable_Visual.xlsx`**: Synthesize your analytics with powerful Pivot Tables, calculations, slicers, and interactive visualization charts.

## 🚀 Getting Started

1. **Clone or Download the Repository:**
   Click the green **`< Code >`** button at the top right of this page and select **Download ZIP**, or run the following command in your terminal:
   ```bash
   git clone https://github.com
   ```
2. **Open the Files:** Ensure you have Microsoft Excel (2016 or newer recommended for Power Query and Data Modeling compatibility) installed on your desktop.
3. **Follow the Sections:** We recommend progressing linearly from **Section 1** through **Section 5** to systematically ramp up your skills.

## 📈 Learning Objectives

* **Data Manipulation:** Cleaning raw datasets and handling missing or malformed inputs.
* **Aggregations & Reports:** Building robust, dynamic summaries using Pivot Tables.
* **ETL Workflows:** Utilizing Power Query to automate repetitive data prep steps.
* **Data Architecture:** Structuring custom data models and utilizing DAX for tailored analytics.
